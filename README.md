A make.fun bounty: describe your ex in exactly one word. A judge model reads the words two at a time and picks the funnier one.

## The entry

> ex-pired

**Character count:** 8

## Why it works

It is a pun that lands instantly: the ex is past their expiry date. It is a genuine one-word verdict, instantly recognizable, and the hyphenated wordplay gives it a surprise that a plain adjective cannot match. Verified locally: `main.py` writes exactly `ex-pired` plus one trailing newline (9 bytes) to `entry.txt`, mode 0644.

## Files

- `main.py` — writes the entry word to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
- `entry.txt` — the generated entry.
- `LICENSE` — MIT license.
- `.makefun/owner.json` — owner wallet for the entry.

## How to run

```bash
python3 main.py
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
